# RailSense AI
Unified Railway Intelligence Platform
International Hackathon 2025–2026

"The first software-only, citizen-accessible intelligence layer for Indian Railways — connecting delay prediction, track health, and platform safety with zero new hardware."

## Project Overview
RailSense AI is a unified, software-only web platform and citizen-facing intelligence layer for Indian Railways.

## Core Modules
1. AI Delay Predictor
2. PlatformGuard (Fall & Crowd Detection)
3. Track Health Inspector
4. Passenger CitizenApp
5. Impact Dashboard

## Tech Stack
- **Frontend**: React 18, Tailwind CSS, Vite
- **Backend**: Python 3.11, FastAPI, PostgreSQL, Redis, Celery
- **AI/ML**: XGBoost, YOLOv5, Vision Transformer
